# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.x     | ✅ Active development |
| < 3.0   | ❌ |

## Reporting a Vulnerability

This project is a personal cybersecurity portfolio. If you discover a security
vulnerability in the codebase, please report it privately.

**Do not** report vulnerabilities via public GitHub issues.

Email: security [at] cybernexus [dot] io

You will receive a response within 48 hours. If the issue is confirmed, a fix
will be prioritized and released as soon as possible.

## Scope

- The portfolio website and its source code
- Demo/simulated data (clearly labeled)

## Out of Scope

- External dependencies (report to respective maintainers)
- Live infrastructure or production credentials (none are stored in this repository)
- Third-party platforms referenced in demo data (TryHackMe, HTB, etc.)

## Disclosure Policy

We follow coordinated disclosure: 90-day grace period after fix release before
public disclosure.

## Transparency

All data in this repository is either:
- **LIVE**: Real portfolio data
- **DEMO**: Example/simulated data for educational purposes
- **HIST**: Historical records
- **SIM**: Simulated scenarios

No real credentials, flags, API keys, or private infrastructure details
are ever included in this repository.
